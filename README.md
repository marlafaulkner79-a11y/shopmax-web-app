# ShopMax public download website

This is a static ShopMax landing/download page designed for GitHub Pages.

## Before publishing
1. Create a public repository named `marlafaulkner79-a11y.github.io`.
2. Upload the contents of this folder to the repository root.
3. Create a GitHub Release in the ShopMax download repository and upload the APK as `ShopMax-1.0.apk`.
4. Replace `DOWNLOAD_URL_PLACEHOLDER` in `index.html` with the release asset URL.
5. Enable GitHub Pages for the website repository.

GitHub Releases support binary assets and a stable latest-release download URL. The page itself should remain a static information/download site rather than the ShopMax SaaS backend.
